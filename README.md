# conchocon154.github.io

Source for my portfolio at **https://conchocon154.github.io**.

Hand-written HTML, CSS and vanilla JavaScript — no framework, no build step, no
tracker. Every chart on the page is generated by the repository it belongs to;
none of them are mock-ups.

```
index.html            the whole page
assets/css/style.css  theme tokens, layout
assets/js/main.js     theme + language toggles, scroll reveal
assets/img/           charts copied from the project repositories
```

Bilingual English / Vietnamese: both languages are in the markup, and the
toggle flips a `data-lang` attribute on `<html>`. The theme toggle works the
same way with `data-theme`, defaulting to the visitor's system preference.

## Local preview

```bash
python3 -m http.server 8080
```
